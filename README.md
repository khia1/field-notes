# Field Notes

## Contents

- **[career/](./career)** — Notes on professional growth, job search, and lessons from the process.
- **[tech-notes/](./tech-notes)** — General technical notes and things learned while building or debugging.
- **[projects/](./projects)** — Small builds, experiments, and writeups about things made.
- **[reflections/](./reflections)** — General thoughts, not tied to a specific topic.

Mostly so I have somewhere to put things down as I work through them — and so the thinking is visible somewhere, not just in my head.
